Guía de Configuración

Pasos para preparar una cuenta AWS antes de ejecutar el análisis.

1

Crear el rol IAM

  1. Ingresa a la consola de AWS → IAM → Roles → Create role
  2. En "Trusted entity type" selecciona Custom trust policy
  3. Pega la Trust Policy del Paso 2 y haz clic en Next
2

Trust Policy — copiar y pegar

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Principal": {
                "AWS": "arn:aws:iam::590183851235:role/infra-explorer-lambda-role"
            },
            "Action": "sts:AssumeRole"
        }
    ]
}
3

Asignar permisos

  1. En la búsqueda de políticas escribe ReadOnlyAccess
  2. Marca la casilla (es una AWS managed policy)
  3. Clic en Next
4

Nombrar el rol

En "Role name" escribe exactamente:

infra-explorer-read-only

Clic en Create role
