ℹ️ ¿Qué es el Health Score?

Puntuación automática de 0 a 100 que resume la seguridad y las buenas prácticas de una cuenta AWS. Se calcula con reglas fijas en cada análisis.

Cómo se calcula: toda cuenta parte de 100 y pierde puntos por cada tipo de problema detectado.

⚠️ Cada tipo de problema resta una sola vez, sin importar cuántos recursos lo tengan. Ejemplo: 8 usuarios sin MFA cuentan como un único problema (−10), no como −80. En el listado de 🚨 Alertas verás los 8 por separado, pero al score solo le resta una vez.

Escala de colores

🟢 80 o más — Saludable 🟡 50–79 — Mejorable 🔴 menos de 50 — Crítico ⚪ Sin análisis

Penalización por tipo de problema

Problema detectado Puntos Severidad
RDS accesible públicamente−15🔴 Crítica
Security Group con TODOS los puertos abiertos a internet−15🔴 Crítica
SSH (22) o RDP (3389) abierto a internet−15🔴 Crítica
Puerto de base de datos (3306, 5432, 1433…) abierto a internet−10🟠 Alta
Cualquier otro puerto abierto a internet (0.0.0.0/0)−10🟠 Alta
RDS sin Multi-AZ (sin alta disponibilidad)−10🟠 Alta
Usuario IAM sin MFA habilitado−10🟠 Alta
Rango amplio de puertos (más de 100) abierto a internet−5🟡 Media
VPC con un solo NAT Gateway (sin redundancia)−5🟡 Media
Instancia EC2 detenida (stopped)−5🟡 Media
Elastic IP sin asociar (coste innecesario)−3🔵 Baja
Instancias EC2 sin tag Name−2⚪ Info

Las severidades menores (🔵 Baja + ⚪ Info) no pueden restar más de 10 puntos en total.

Ejemplo

Cuenta con SSH abierto, otro puerto abierto a internet, 8 usuarios sin MFA, 2 EC2 detenidas y un solo NAT Gateway:

100 − 15 − 10 − 10 − 5 − 5 = 55

💡 El score se recalcula en cada análisis. Mira la pestaña 🚨 Alertas para ver el detalle de cada hallazgo.

Guía de Configuración

Pasos para preparar una cuenta AWS antes de ejecutar el análisis.

1

Crear el rol IAM

  1. Ingresa a la consola de AWS → IAM → Roles → Create role
  2. En "Trusted entity type" selecciona Custom trust policy
  3. Pega la Trust Policy del Paso 2 y haz clic en Next
2

Trust Policy — copiar y pegar

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Principal": {
                "AWS": "arn:aws:iam::590183851235:role/infra-explorer-lambda-role"
            },
            "Action": "sts:AssumeRole"
        }
    ]
}
3

Asignar permisos

  1. En la búsqueda de políticas escribe ReadOnlyAccess
  2. Marca la casilla (es una AWS managed policy)
  3. Clic en Next
4

Nombrar el rol

En "Role name" escribe exactamente:

infra-explorer-read-only

Clic en Create role
